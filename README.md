# Ultimate AI Prompt Generator

AI-powered standalone prompt generation tool.

## Plans
- Free: 5 prompts/day
- Pro: ₹299/month, 25 prompts/day
- Ultimate: ₹499/month, 50 prompts/day

## Run locally
1. npm install
2. Copy .env.example to .env.local
3. Add GEMINI_API_KEY
4. npm run dev

## Security
Never commit your real Gemini API key. Keep it in environment variables.
